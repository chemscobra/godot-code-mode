# godot-cm — native core

C++ GDExtension core for the Godot Code Mode MCP addon: MCP transport,
QuickJS-NG runtime, and the editor bridge.

## Pinned versions

| Component    | Version           | Notes                                        |
|--------------|-------------------|----------------------------------------------|
| Godot        | 4.7.2 stable      | Declared floor: 4.7; validated only on 4.7.2 |
| godot-cpp    | branch `4.7`      | submodule at `../godot-cpp`                  |
| QuickJS-NG   | v0.18.0           | released 2026-11-01, vendored                |
| MCP spec     | 2025-11-25        | JSON-RPC 2.0, Streamable HTTP + stdio        |
| extension_api| `../api/` dump    | generated by local 4.7.2 binary              |

## Platform matrix (MVP)

| Platform       | Status                     |
|----------------|----------------------------|

| windows-x86_64 | compile only, post-MVP     |
| macos          | compile only, post-MVP     |

## Layout

- `src/` — C++ sources (this dir)
- `addon/godot_cm/` — distributable addon (`.gdextension`, plugin, `bin/`, `.d.ts`)
- `godot-cpp/` — godot-cpp submodule (branch 4.7)
- `godot-cm/` — demo host project; mounts the addon via `addons/godot_cm` symlink
- `api/` — `extension_api.json` + `gdextension_interface.h` dumped from Godot 4.7.2
